# Feature Tickets

This folder contains feature tickets that track features through the development lifecycle.

## Ticket Format

Each ticket should follow this format:

```markdown
# TICKET-NNN: <Feature Name>

## Status
<!-- Vision | Decomposition | Design | Implementation | Integration | Testing | Deployment | Complete -->

## Priority
<!-- Critical | High | Medium | Low -->

## Description
<!-- What does this feature do? -->

## User Story
<!-- As a <user>, I want <goal>, so that <benefit>. -->

## Acceptance Criteria
<!-- What must be true for this feature to be complete? -->
- [ ] 
- [ ] 
- [ ] 

## Affected Modules
<!-- Which parts of the system are affected? -->

## Dependencies
<!-- What does this feature depend on? -->

## Assigned Skills
<!-- Which agent skills are needed? -->

## Notes
<!-- Additional context or links. -->
```

## Naming Convention

Files: `ticket-NNN-<short-description>.md` (e.g., `ticket-001-user-onboarding-flow.md`)
