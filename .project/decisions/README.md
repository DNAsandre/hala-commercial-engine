# Architecture Decision Records (ADRs)

This folder contains Architecture Decision Records — structured documents that capture important architectural and project decisions.

## ADR Format

Each ADR should follow this format:

```markdown
# ADR-NNN: <Title>

## Status
<!-- Proposed | Accepted | Deprecated | Superseded -->

## Date
<!-- YYYY-MM-DD -->

## Context
<!-- What is the issue or question being addressed? -->

## Decision
<!-- What was decided? -->

## Consequences
<!-- What are the positive and negative consequences of this decision? -->

## Alternatives Considered
<!-- What other options were evaluated? Why were they rejected? -->
```

## Naming Convention

Files: `adr-NNN-<short-description>.md` (e.g., `adr-001-use-supabase-for-auth.md`)
