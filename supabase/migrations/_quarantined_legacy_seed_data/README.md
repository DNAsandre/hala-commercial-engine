Legacy Seed Data
================

Files in this folder are quarantined because they write prototype or inline
configuration records into Supabase.

Do not run these migrations against Supabase without a fresh lineage review.

Current doctrine:
- Operational and governance records must be created from verified sources or
  through governed admin workflows.
- Audit records must be generated by real application actions.
- Local seed files must not invent users, approvals, gates, or business facts.

Quarantined in this cleanup pass:
- `20260506_supa006_linde_seed.sql` inserted a Linde tender plus mock/test
  packs, gates, outputs, activity, audit, and submission-email records.
- `20260507_supa006b_tender_parity_seed.sql` inserted additional Linde
  required documents, compliance items, split checks, test outputs, and
  mock submission emails.
