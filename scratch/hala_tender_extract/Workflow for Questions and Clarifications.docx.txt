2. Bot-Friendly Markdown Guide (for instruction prompts)
# Tender / RFQ Response Methodology
## Phase 1: Intake & Registration
- Capture RFQ ID, title, buyer, deadlines.
- Note submission format/portal.
- Assign bid manager & team.
## Phase 2: Document Review
- Read full RFQ once (no notes).
- Split into sections: scope, compliance, evaluation, commercial, forms.
- Build **Compliance Matrix** (requirement → plan → owner → status).
## Phase 3: Clarifications
- Identify unclear/missing/contradictory items.
- Draft **questions**: include RFQ reference/page.
- Submit via correct channel before deadline.
- Maintain **Clarification Log** and update compliance.
## Phase 4: Win Strategy
- Create 3–5 win themes linked to buyer evaluation.
- Map strengths/differentiators to requirements.
- Conduct **bid/no-bid** check.
## Phase 5: Drafting
- **Technical Volume**: Exec summary → Understanding → Methodology → Team → Risk/HSE/QA → Compliance → Deliverables.
- **Commercial Volume**: Pricing summary → BOQ breakdown → Assumptions → Options → Terms.
- Ensure consistency between technical & commercial.
## Phase 6: Review & QA
- Run Red Team (independent compliance review).
- Confirm all mandatory forms attached.
- Check formatting, branding, bilingual content.
## Phase 7: Finalization & Submission
- Package per RFQ rules (copies, labels, encryption).
- Include bonds/guarantees if required.
- Submit on time.
- Archive submission + lessons learned.
