# **4\. THE FOUR OPERATING LOOPS**

Every task uses one of these loops:

---

### **Loop 1 — Feature Loop (Building Something New)**

Used when:

* You want to create a new page

* Add a feature

* Create components

* Build UI

* Add automation

* Expand the app

Flow:

1. You explain your idea

2. META Agent asks minimal clarifiers

3. META Agent builds the structured blueprint

4. Codex executes and updates repo

5. System returns updated code

---

### **Loop 2 — Fix Loop (Debugging / Errors)**

Used when:

* Something breaks

* Code throws errors

* App crashes

* Build fails

Flow:

1. You provide the error

2. META Agent extracts context

3. META Agent selects correct debugging rules

4. Codex fixes the bug

5. Codex validates fix

---

### **Loop 3 — Refactor Loop (Improve Existing Code)**

Used when:

* Code is messy

* Naming needs clean-up

* Folder structure changes

* System scalability required

Flow:

1. You specify improvement goal

2. META Agent assesses risk

3. META Agent builds refactor plan

4. Codex executes refactor

5. Codex checks for breakage

---

### **Loop 4 — Knowledge Loop (Document → Understanding → Behavior)**

Used when:

* You onboard new AI agents

* You add new rules

* You evolve the architecture

* You customize behaviors

Flow:

1. You provide new document

2. META Agent interprets

3. System updates its internal governance

4. All agents now operate under new rules

---

# **5\. THE FIVE PHASES OF EVERY TASK**

This is your **universal workflow**, regardless of complexity:

1. **Initiate** — You describe what you want

2. **Clarify** — META Agent asks only needed questions

3. **Translate** — META Agent forms the full blueprint

4. **Build** — Codex constructs it

5. **Validate** — System checks work and returns it to you

This simple five-phase loop makes everything predictable.

# **7\. RULES FOR META INTERROGATION**

META Agent MUST:

* Ask only essential questions

* Stop interrogating once enough META is captured

* Never ask more than is needed

* Never loop

* Never block Codex

* Always form a Codex-ready blueprint

* Always maintain your meaning and intent

* Transform high-level ideas into structured engineering logic

Stopping conditions (mandatory):

* If META is sufficient to build, **stop**

* If user signals “Ready to build”, **stop**

* If request is small (UI components etc), limit to **1–2 questions**

* If Codex can infer the rest, do not ask

---

# **10\. STOPPING CONDITIONS FOR ALL AGENTS**

An agent must STOP when:

* Goal is satisfied

* A complete blueprint is formed

* Code is successfully generated

* Deployment is complete

* User says “stop”, “enough”, or “build now”

* Next agent is ready for handoff

* Further questioning adds no value

This prevents infinite loops.
