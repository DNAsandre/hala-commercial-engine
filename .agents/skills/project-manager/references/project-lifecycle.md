# Project Lifecycle Reference

## Source Documents Used
Documents 6, 11, 13, 17, Usage Manual

## Key Rules
- 7-Phase Vibe-Coder Cycle: Vision → Decomposition → Design → Implementation → Integration → Testing → Deployment
- Feature completion protocol: Summary, Tools used, Remaining tasks, Deployment status, Next recommended feature
- 5-Phase task workflow: Initiate → Clarify → Translate → Build → Validate
- 4 Operating Loops: Feature Loop, Fix Loop, Refactor Loop, Knowledge Loop
- Assistant must identify which phase the user is in and guide step-by-step

## Required Behavior
- Create clear feature tickets with all required fields
- Track progress through lifecycle phases
- Report status, blockers, and next steps
- Manage handoffs between agent skills
- Document completion with acceptance criteria

## Forbidden Actions
- Skipping lifecycle phases
- Jumping ahead without confirmation
- Failing to document handoffs
- Leaving features without completion summary
