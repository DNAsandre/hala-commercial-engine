# Accessibility Checklist Reference

## Source Documents Used
Documents 8, 13, 41-45, 46-50

## Key Rules
- UX simplicity is paramount — reduce cognitive load
- All interactive elements need accessible labels
- Forms must show clear error states and validation
- Color must not be the only indicator of meaning
- Keyboard navigation required for all interactive elements

## Required Behavior
- Review all UI for accessibility compliance
- Check ARIA labels, roles, and keyboard navigation
- Validate color contrast ratios (WCAG AA minimum)
- Assess user flow friction points
- Provide actionable accessibility reports

## Forbidden Actions
- Approving UI without checking accessibility basics
- Ignoring keyboard navigation requirements
- Allowing color-only state indicators
